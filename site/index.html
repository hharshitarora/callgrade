callgrade

Grade your voice agent's calls, from any platform, and know whether to trust the grade.

GitHub Quickstart pip install "callgrade[anthropic] @ git+https://github.com/hharshitarora/callgrade"

Watch it grade

Three calls from the held-out test set, with the verdict the default judge gave each one. Timing comes from the timestamps in plain code. The verdict comes from an LLM reading a rubric, and it has to say which turn before it gives a number.

How far to trust it

A judge is a model, so callgrade measures the judge. Each judge graded each set three times. A planted failure counts as caught only if every run caught it, and every rate carries a 95% interval, because 9 of 9 on a small set is a range, not a certainty.

Where it came from

The first version was a sheet I filled in by hand to score test calls for a voice agent that qualified rental leads. The sheet became an LLM judge on four dimensions, and that judge is what moved the agent from "it feels off" to "it misreads intent when the caller says they need to think about it". This is the open version, with platform adapters, measured timing checks, and the agreement measurements the original never had.

Design choices are in DECISIONS.md. Every failure the test sets cover is in the failure catalog.
