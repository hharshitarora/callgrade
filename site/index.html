Grade your voice agent's calls. Then grade the grader.

callgrade reads a call export from any platform, times every reply with plain code, has an LLM score it against a rubric, and measures how far that score can be trusted.

Every call, every run

Two judges graded every call three times. One square per run. A planted failure counts as caught only at the minimum score, the same bar that makes a clean call a false alarm, so a judge that merely docks a point for the planted failure does not get credit.

How far to trust it

Every rate carries a 95% interval, because 9 of 9 on a small set is a range, not a certainty. The held-out set was written after the rubrics were tuned on the development set, and committed before any judge saw it.

How far the two judges agree with each other, as quadratic weighted kappa. 1 is perfect, 0 is chance, and 0.6 is a common bar for a judge that gates a release.

No person has scored either set yet. That check exists in the tool (callgrade agree --human) and has not been run.

Where it came from


The first version was a sheet I filled in by hand to score test calls for a voice agent that qualified rental leads. The sheet became an LLM judge on four dimensions, and that judge is what moved the agent from "it feels off" to "it misreads intent when the caller says they need to think about it". This is the open version, with platform adapters, measured timing checks, and the agreement measurements the original never had.


Design choices are in DECISIONS.md. Every failure the test sets cover is in the failure catalog.
