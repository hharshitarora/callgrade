Grades voice agent calls. Then grades the grader.

Point it at the call exports you already have. Plain code times every reply. A model scores the call against a rubric and has to name the turn before it gives a number. Then the judge itself gets measured, because a judge is a model too.

02Every call, every run

Three judges, every call, three runs each. One square per run. A planted failure only counts as caught at the minimum score, which is the same bar that turns a clean call into a false alarm. Docking one point for a planted failure doesn't count. I made that rule after the first run looked better than it was.

03How far to trust it

Every rate comes with a 95% interval. 9 of 9 on 9 calls means somewhere between 70% and 100%, and I'd rather the page said so than me. The held-out set was written after the rubrics were tuned on the development set and committed before any judge saw it. The development numbers flatter the judge a bit. The held-out ones are the ones to quote.

How much the judges agree with each other, pair by pair, as quadratic weighted kappa (1 is perfect agreement, 0 is chance, and 0.6 is where people usually let a judge gate a release). The one number under 0.6 is Haiku and GPT reading the same awkward call differently every single run.

Nobody has scored either set by hand yet. The tool has the command for it (callgrade agree --human), I just haven't sat down and done the 14 calls. It's next.

Look at the run that scored a 1. The reason it wrote describes a 0. No rubric wording fixes a judge that contradicts itself in the same breath, and honestly this is why I don't trust totals on their own.

iii.

The expensive judge disagrees with the other two on one clean call. In c04 the agent says it'll put a pet request to the landlord and call back by Thursday. Haiku and GPT pass it every run. Sonnet blocks it every run:

The context file says pets need the landlord's consent and says nothing about callbacks. So by my answer key the call is clean, and by a strict reading "by Thursday" is a promise nobody authorised. Sonnet has a point. One line in the context about callbacks would settle it either way, and I left it alone because that is exactly the kind of line --context exists for.

06Where it came from




The first version was a scoring sheet I filled in by hand, seven rows, 0 to 2 each, for test calls on a voice agent that qualified rental leads. Listening to calls doesn't scale past a handful a day, so the sheet became an LLM judge on four dimensions. That judge is what got the agent from "it feels off" to "it misreads intent when the caller says they need to think about it", which you can actually fix. This is the open version. It has the platform adapters and the timing checks the original never had, and the part I care about most, the measurements of the judge itself.


Design choices are in DECISIONS.md. Every failure the test sets cover is in the failure catalog.
